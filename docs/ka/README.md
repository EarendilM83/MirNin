# LMS — სისტემის აღწერა (ქართული)

ამ საქაღალდეში მოთავსებულია სასწავლო პროცესის მართვის სისტემის (LMS) ქართულენოვანი
აღწერა — ექსპერტებისთვის გასაგები, ვიზუალურად გამყარებული დოკუმენტი.

## ფაილები

| ფაილი | აღწერა |
|---|---|
| `LMS-sistemis-aghwera-KA.docx` | **ძირითადი დოკუმენტი** — Word ფორმატში, ჩაშენებული ეკრანის სურათებით |
| `LMS-sistemis-aghwera-KA.html` | იგივე დოკუმენტი ვებ-ფორმატში (თვითდაცული, ბრაუზერში გასახსნელი) |
| `screens/` | სისტემის ეკრანის სურათები (s1–s7) |
| `build/` | გენერაციის სკრიპტები (რეპროდუცირებადობისთვის) |

## შინაარსი

1. სისტემის მიმოხილვა — სამი აპლიკაცია (ვები / მასწავლებელი / სტუდენტი)
2. სისტემის არქიტექტურა და აპლიკაციები
3. მომხმარებლის 7 როლი და უფლებამოსილებების მატრიცა
4. **შეფასების პროცესი და მოდელები** — მოდელები, კატეგორიები, წონები, ბარიერები, ECTS
5. მასწავლებლის მხარე
6. სტუდენტის მხარე (Duolingo-ს მსგავსი აპლიკაცია)
7. ონლაინ შეფასება და აკადემიური კეთილსინდისიერების კონტროლი (დაცული რეჟიმი, ჩანართის
   გადართვის აღკვეთა, მოწყობილობის მონიტორინგი)
8. შემაჯამებელი

## რეგენერაცია

```bash
npm install docx            # თუ დაყენებული არ არის
node docs/ka/build/gen-html.cjs
node docs/ka/build/gen-docx.cjs
```

ეკრანის სურათები აღდგება `build/screens-mock.html`-იდან (Playwright + Chromium).

> შენიშვნა: ეკრანის სურათები აღწერს დაგეგმილ ინტერფეისს; აკადემიური კეთილსინდისიერების
> კონტროლის ცალკეული ფუნქცია (ვებ-ვერსიის დაცული რეჟიმი) კურსის დაწყებამდე ინერგება.
